## Responsibilities of this repository

`ai-sdk-go` is the official OpenStrata developer library for the **Go ecosystem**
(module `github.com/open-strata-ai/ai-sdk-go`). It is a three-layer lightweight
"client + builder + extension port" library — **not** a deployable service. It lets
Go applications embed a conversational Agent/Client and reach platform runtime
capabilities (Gateway, Agent runtime, tool registration, memory, RAG, cache,
observability) with minimal intrusion.

- **Exposes/depends on 15 platform SPI ports** (see `docs/ARCH.md` §3 / `docs/DESIGN.md` §6):
  `Gateway`, `AgentRuntime`, `LLMProvider`, `VectorStore`, `Cache`, `Auth`,
  `Tracing`, `RAG`, `LowCode`, `Workflow`, `Sandbox`, `CICD`, `MultiTenancy`,
  `MLOps`, `Eval` — all defined in `pkg/domain` as framework-free interfaces.
- **First-class objects**: `Client` (pkg/client), `AgentBuilder`/`AgentSpec`
  (pkg/agent, pkg/domain), `Tool`, `Session`, `Retriever` (pkg/domain).
- **Default adapters** (all stdlib-only, offline/test-friendly) live in `pkg/adapter`
  (echo LLM, in-memory cache/vector store, local agent runtime/auth, no-op tracing,
  logging RAG/gateway/workflow/sandbox/cicd/mlops/eval/multitenancy). Hosts replace
  any port by injecting their own implementation (dependency inversion).
- **External components**: none required at runtime. `HTTPGateway` uses only
  `net/http` to call the platform Gateway; no third-party module dependency.

Configuration is loaded by `config.Load(config.FromEnv(), config.FromFile("infrastructure/config/client.yaml"))`
with priority: explicit option > env > file > defaults. See `docs/DESIGN.md` §7.

### Quickstart

```go
package main

import (
    "context"
    "github.com/open-strata-ai/ai-sdk-go/pkg/agent"
    "github.com/open-strata-ai/ai-sdk-go/pkg/client"
    "github.com/open-strata-ai/ai-sdk-go/pkg/domain"
)

func main() {
    c := client.NewDefault(nil) // stdlib default adapters, offline

    resp, _ := c.Chat(context.Background(), domain.ChatRequest{
        Messages: []domain.ChatMessage{{Role: "user", Content: "Where is my order?"}},
    })
    _ = resp

    spec := agent.New(c.AgentRuntime(), "customer-service-v2").
        Tenant("tenant-b").
        ModelBinding(&domain.ModelBinding{Primary: "cloud-qwen-max"}).
        InputSchema(domain.NewObjectSchema("query", "string")).
        OutputSchema(domain.NewObjectSchema("answer", "string")).
        Guardrails(&domain.Guardrails{Checks: []string{"injection_scan", "pii_scan"}}).
        Build()

    h, _ := c.AgentRuntime().Load(context.Background(), spec)
    out, _ := c.AgentRuntime().Run(context.Background(), h, map[string]any{"query": "hi"})
    _ = out
}
```
